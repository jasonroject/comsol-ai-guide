## 快速开始

环境要求：Windows、Python、已安装且具有适用许可证的 COMSOL。已验证版本为 COMSOL 6.3；Python 运行器仅使用标准库。按本机修改 COMSOL 安装路径。

```powershell
python run_smoke.py `
  --comsol-bin "C:/Program Files/COMSOL/COMSOL63/Multiphysics/bin/win64" `
  --out ./runs/conduction_001 `
  --cores 1 --timeout 180
```

输出目录必须尚不存在。脚本会编译 Java，在一个独立 batch 进程内创建二维导热模型、求解并保存 `smoke.mph`，再启动第二个 batch 进程读取保存解、清空原解并重新求解。日志、模型、数值检查和 `report.json` 全部保存在输出目录。

退出码 0 且报告中 `status=passed` 表示该示例通过。超时后运行器只终止直接创建的子进程；进一步清理前需要核对后代进程归属。

## 给其他 AI 使用

将 [执行指南](GUIDE.zh-CN.md) 提供给具备本地文件、命令或 COMSOL MCP 操作能力的 AI，并补充目标、几何、材料、方程、边界条件和数据来源。指南末尾附有可复制的启动提示词。

指南涵盖 Java 批处理与 MCP 路线、几何选择、材料覆盖、耦合、求解状态、数据集与单位、网格及时间步验证、自动调试、超时恢复和保存重开验收。

示例验证自动化调用链及线性导热解析解，不代表复杂多物理场模型已通过科学验证。MPh 和所述本地 MCP 均为第三方封装；本项目不是 COMSOL 官方项目。
